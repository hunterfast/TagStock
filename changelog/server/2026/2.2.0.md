# Server 2.2.0

_Stand: 2026-09-11_

## Neu
- **Behälter: ein Lager im Lager.** Eine Box, eine Schublade, ein Regal – jeder
  Artikel kann als Behälter geführt werden und andere aufnehmen. Verbunden wird
  über die **Kennung** des Behälters: Die klebt am Möbel, wird beim Einräumen
  gescannt und bedeutet in der App, im Browser und auf dem Server dasselbe.

  In der Weboberfläche:
  - im Artikelfenster der Haken *„Ist selbst ein Behälter"*, die Art und die
    Auswahl *„Liegt in"*,
  - im Behälter selbst eine Liste seines Inhalts, aus der man hineinspringt,
  - in der Werkzeugleiste ein Filter: *Nur Behälter*, *Nicht eingeräumt* oder
    gezielt *In: Ikea-Box blau*,
  - in der Liste ein ▦ vor Behältern samt Art und Stückzahl, und bei allem
    Eingeräumten steht „in Ikea-Box blau" beim Ort.

- **Behälter dürfen ineinanderstecken**, aber nicht im Kreis. Der Server prüft
  das bei jedem Speichern und lehnt einen Ring mit einer klaren Meldung ab –
  auch über mehrere Ecken.

## Regeln
- Ein Behälter **braucht eine eigene Kennung**, sonst wird er nicht angenommen.
- Bekommt ein Behälter eine **neue Kennung**, zieht sein Inhalt mit.
- Wird er **gelöscht** oder ist er kein Behälter mehr, wird sein Inhalt frei –
  er zeigt dann auf nichts mehr, statt unauffindbar zu werden. Beides steht im
  Protokoll.

## Datenbank
Drei neue Spalten in `artikel`: `ist_behaelter`, `behaelter_art`,
`behaelter_kennung`. Eine bestehende Datenbank wird beim Start selbst ergänzt –
es ist nichts von Hand zu tun.
