# Server 2.0.0

_Stand: 2026-09-10_

## Neu
- Artikelbilder: ablegen, ausliefern und entfernen. Der Server prüft das Format
  am Inhalt, nimmt JPEG, PNG und WebP und legt die Datei im Volume ab.
- Nachschlagedienst für Handelsnummern mit Zwischenspeicher; gefragt wird
  höchstens einmal je Nummer, auch ein Fehlschlag wird gemerkt.
- Der Server erkennt, wenn es einen neueren Stand gibt, und sagt es der App.
- Er hält die App bereit: aktuelle und vorherige Fassung, damit ein Gerät im
  Notfall zurück kann. Fehlt die aktuelle, holt er sie selbst.
- Startseite unter `/` mit Logo, Version und Zustand; `/icon.png` für die
  Kachel in Unraid.
- `update.sh`: Stand holen, Daten sichern, Abbild bauen, Container neu starten.

## Geändert
- Version und Bauzeitpunkt stehen in `/api/v1/status`.
- Vor dem Wechsel auf eine neue App-Fassung legt der Server eine Sicherung der
  Datenbank an, die zu der bisherigen Fassung passt.

## Behoben
- Beim Aktualisieren blieben fehlende Spalten in bestehenden Tabellen liegen –
  `CREATE TABLE IF NOT EXISTS` fasst eine vorhandene Tabelle nicht an. Der
  Server ergänzt sie jetzt beim Start.
- Das Docker-Abbild ließ sich nicht mehr bauen, weil das Basis-Abbild inzwischen
  selbst einen Benutzer mit der Kennung 1000 mitbringt.
