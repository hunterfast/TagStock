# Server 2.4.1

_Stand: 2026-10-15_

Passend zur App 2.2.1.

## Behoben
- **Gelöscht bleibt gelöscht.** Schickte ein Gerät, das von einer Löschung
  noch nichts wusste, eine spätere Änderung an dem Artikel, stand er wieder
  auf. Jetzt bekommt das Gerät zur Antwort, dass der Artikel gelöscht ist, und
  löscht ihn ebenfalls.

- **Doppelt gelöscht.** Ein zweites Löschen desselben Artikels (etwa von zwei
  Geräten) schrieb einen zweiten Protokolleintrag und meldete den Artikel
  erneut an alle Geräte. Jetzt antwortet der Server „nicht gefunden" und lässt
  es dabei.

- **Abgelehntes kommt mit dem Serverstand zurück.** Lehnte der Server die
  Änderung eines Geräts ab, weil er eine neuere Fassung hatte, schickte er diese
  nur mit, wenn sie seit dem letzten Abgleich des Geräts entstanden war. Sonst
  behielt das Gerät seine abgelehnte Fassung, und beide liefen auseinander.

- **Menge im Formular der Weboberfläche.** Setzt man dort die Menge auf 0,
  steht der Artikel jetzt auf *nicht vorhanden* – wie beim Entnehmen – und
  wieder auf *vorhanden*, wenn etwas dazukommt. Ein im selben Zug von Hand
  gewählter Status bleibt, wie er ist.
