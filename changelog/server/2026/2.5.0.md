# Server 2.5.0

_Stand: 2026-10-26_

Passend zur App 2.3.0.

## Neu
- **Zusammenführen statt Überschreiben.** Die App schickt zu jedem Artikel mit,
  von welchem Stand sie ausging. Haben inzwischen beide Seiten geändert, führt
  der Server zusammen: Mengen werden verrechnet (von 10 nimmt das eine Handy
  2, das andere 1 – es bleiben 7), verschiedene Felder bleiben beide erhalten,
  beim selben Feld gewinnt die spätere Änderung. Hat die Zusammenführung die
  Menge bestimmt, folgt ihr auch der Status – bei 0 *nicht vorhanden*, sonst
  *vorhanden*.

## Behoben
- **Nachgereichtes Protokoll ging verloren.** Die Geräte bekamen Einträge nach
  ihrem Zeitpunkt. Was ein Handy nachreichte, das eine Weile ohne Netz war, lag
  damit vor dem letzten Abgleich der anderen – und kam dort nie an. Jetzt zählt,
  wann der Eintrag beim Server eingegangen ist.
- **Mehr als 500 Einträge auf einmal** wurden abgeschnitten, und der Rest war
  für das Gerät verloren. Die Grenze ist weg.
- Einträge zu Artikeln, die im selben Abgleich erst angelegt wurden, hatten
  keinen Artikel. Jetzt setzt der Server ihn selbst ein.

Die Datenbank bekommt beim Start eine neue Spalte, ohne dass jemand eingreifen
muss.
