# Server 2.2.2

_Stand: 2026-09-12_

## Geändert
- Die Statusauskunft nennt jetzt auch, **welchen** Nachschlagedienst der Server
  benutzt (`gtinDienstName`), nicht nur ob einer eingerichtet ist. Die App
  zeigt das in den Einstellungen an – bisher war von außen nicht zu erkennen,
  warum beim Scannen einer Handelsnummer nichts vorgeschlagen wurde.

## Erinnerung
Ohne `TAGSTOCK_GTIN_DIENST` schlägt der Server nichts nach. Zum Einschalten:

```
TAGSTOCK_GTIN_DIENST=opengtindb
```

oder `eansearch` zusammen mit `TAGSTOCK_GTIN_SCHLUESSEL`. Die Nummer verlässt
dabei das eigene Netz – jede nur einmal, danach bedient der Zwischenspeicher.
