# Server 2.3.0

_Stand: 2026-09-12_

## Neu
- **Menge und Verpackungseinheit** – dieselben Felder wie in der App:
  `menge`, `istVerpackung`, `packungsGroesse` und `angebrochen` (die Reste der
  angebrochenen Packungen als `"2,3"`, denn es können mehrere offen sein).

- In der Weboberfläche stehen die Felder im Artikelfenster, mit einer
  mitrechnenden Zusammenfassung („Gesamt 25 Stück – 5 volle Packungen à 4,
  dazu 2 + 3 in den angebrochenen"). In der Liste gibt es eine Spalte *Menge*:
  groß die Packungen, klein darunter die Einzelteile.

- **Entnehmen, Zugang, Packung anbrechen** als Knöpfe im Artikelfenster. Sie
  gehen über `POST /api/v1/teams/{team}/artikel/{id}/menge` – der Server
  rechnet, damit im Browser dieselbe Regel gilt wie in der App: zuerst die
  angebrochene Packung leeren, dann die nächste anbrechen.

- Fällt der Bestand auf 0, setzt der Server den Status auf *nicht vorhanden*;
  bei einem Zugang zurück auf *vorhanden*. Verliehenes und Ausgelagertes
  bleibt unberührt. Jede Änderung steht im Protokoll.

- Widersprüchliche Angaben werden beim Speichern geradegezogen: ein Rest, der
  größer ist als die Packung, wird gekappt, und ohne Verpackungseinheit
  verschwinden Packungsgröße und offene Reste.

## Datenbank
Vier neue Spalten in `artikel`. Eine bestehende Datenbank wird beim Start
selbst ergänzt – es ist nichts von Hand zu tun.
