# App 2.0.6

_Stand: 2026-09-11_

## Behoben
- „Nach Aktualisierungen sehen" meldete „Auf dem Server liegt keine App zum
  Verteilen", ohne zu sagen, warum. Fehlt dem Server der Zugangsschlüssel oder
  kommt er nicht an die Veröffentlichungen, steht der Grund jetzt in der
  Meldung – dort, wo man ihn sucht.
- Der Knopf ließ den Server nicht wirklich nachsehen: Er bekam nur dessen
  letzten Stand, und der wird nur alle sechs Stunden erneuert. Jetzt sieht der
  Server auf Knopfdruck sofort bei der Quelle nach.
